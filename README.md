## Overview

`mrunpack` is a Modrinth modpack (.mrpack) unpacker, it extracts the content and download the mods it requires.
It's useful if your launcher doesn't support playing modpacks.

## How to use

1. Go to [releases](https://github.com/znemux/mrunpack/releases/latest) and download `mrunpack-windows.zip` or `mrunpack.jar`
2. Execute `mrunpack.bat` (the one with gears icon) or `mrunpack.jar`
3. After the app shows up, click the Select file button and browse the file.
4. After selecting the file, click unpack now.
5. If there's an error, report it [here](https://github.com/znemux/mrunpack/issues).
